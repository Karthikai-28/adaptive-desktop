# Component Inventory

## Shell

- Top identity: brand button, project menu, GNOME date menu styling.
- Dock rail: Home, Files, Applications, Workspaces, Command, Open windows, System.
- Open window row: app icon, title, active state, focus action.
- Workspace menu: workspace switch, active-project workspace pin.
- Command menu: desktop actions, applications, projects.
- System Center menu: status rows, volume, audio output, focus, settings, lock/session/power actions.

## Files

- Sidebar: places, projects, pinned folders, network, filesystem, storage summary.
- Browser: grid/list item rows, empty/search-empty state, selection state.
- Preview/Inspector: location preview, folder preview, file preview, metadata, actions.
- Storage panel: capacity ring, volume details, launch helpers.
- Network flow: Samba connect dialog, remote sidebar.

## Settings

- Settings shell: sidebar, search, section content, routed action card.
- Sections: Home, Appearance, Projects & Workspaces, Windows & Multitasking, Notifications & Focus, Search & Commands, Display & Graphics, Sound, Input & Gestures, Network & Connectivity, Files & Storage, Privacy & Security, Accounts & Sync, Power & Battery, Accessibility, Developer & Advanced, Updates/Recovery/Session, About.

## Services

- Project Context: project registry, active project, workspace mapping, project search provider.
- Focus CLI: notification focus status, on/off, timer.

## States To Preserve

- Empty state.
- Error state.
- Hover, focus, active, selected.
- Service offline.
- Verification needed.
- Destructive confirmation routed through GNOME-native controls.
