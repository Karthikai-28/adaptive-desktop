# Adaptive Desktop Icon Family

Adaptive Desktop uses a small symbolic icon family for shell navigation and app
chrome. Icons are simple filled SVGs, sized for 18-24 px use, and avoid text
inside the artwork.

## Shell Dock

- `overview.svg` — Home / overview
- `files.svg` — Adaptive Files
- `apps.svg` — Applications
- `workspaces.svg` — Workspaces
- `search.svg` — Command
- `settings.svg` — System Center

Source path: `shell/adaptive-shell@local/assets/dock/`

## Adaptive Files

Source path: `icons/AdaptiveFilesIcons/` — an icon theme consumed by the
forked Nautilus (and every GTK app in the session), not per-app assets.

`places/`, `devices/` and `mimetypes/` are generated by
`scripts/build-file-icons.py` and must not be edited by hand; change the
tables in the script and rerun it (`verify-all.sh --quick` fails while the
tree is stale). `apps/`, `actions/` and `emblems/` are hand-drawn.

The style is liquid glass on Apple's dark palette:

- Folders: blue glass, the place's glyph engraved on the front plate
  (Documents, Downloads, Music, Pictures, Videos, Home, Desktop, ...).
- Files: a frosted page with a folded corner, the type's glyph in its colour
  and, when the glyph alone cannot tell two types apart, the extension on a
  pill — as Finder's document icons do. The type colours (Apple system
  colours) appear only on file pages; chrome stays single-accent blue.
- Devices and Trash: the same glass, neutral.
- Sidebar and path bar (`*-symbolic`): the bare glyph, drawn from filled
  outlines only, because GTK recolours symbolic icons by overriding `fill`.
- Label text is converted to outlines at build time; no font is needed to
  render an icon.

One glyph library feeds all three, so a folder, its sidebar row and the files
in it share one picture. Coverage spans code (Python, C/C++, CUDA, Arduino,
JS/TS, Java, Kotlin, Rust, Go, Swift, Ruby, PHP, Lua, shell, SQL), config
(JSON, YAML, TOML, ini, `.env`, Git, lock files, protobuf), build (CMake,
Make, Dockerfile), robotics (ROS launch, URDF/Xacro, msg/srv/action, bag,
MCAP, db3, RViz), data and ML (NumPy, pickle, PyTorch, ONNX, safetensors,
HDF5, Parquet, SQLite), 3D meshes, office documents, media, fonts, archives,
packages and binaries.

`icons/adaptive-files-mime.xml` is the other half: Ubuntu 22.04 has no MIME
type for many of these, so without it they are all
`application/octet-stream` and the icon cannot be chosen. It is installed per
user by `scripts/install-adaptive-theme.sh`.

## Rules

- Use SVG viewBox `0 0 24 24` unless an existing icon requires otherwise.
- Prefer a single foreground fill color and let CSS/state containers provide
  hover, focus, and active treatment.
- Keep icons legible at 14 px in toolbar buttons and 20 px in the shell dock.
- Add new icons to this manifest when they become part of user-visible chrome.
