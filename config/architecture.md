# Architecture

Ubuntu
  |
  +-- Standard Ubuntu Session
  |
  +-- Adaptive Desktop Session
       |
       +-- Window Manager / Compositor
       +-- Desktop Shell
       +-- Workspace Engine
       +-- Universal Command Layer
       +-- Project Context Service
       +-- File Explorer Experience
       +-- Settings Experience
       +-- System Center
       +-- Notification Service
       +-- Focus Mode
       +-- Telemetry Layer

The custom session must never be required for Ubuntu to boot.
